# anim-токены: как задавать анимацию прямо в Figma

Шпаргалка для дизайнера. Идея: рядом с именем/классом слоя в скобках писать
**короткий структурированный токен** с описанием анимации этого элемента.
Тогда разработчик (или агент) собирает анимации сразу из макета, не выспрашивая
параметры отдельно.

## Формат

```
ИмяСлоя (ключ: значение; ключ: значение)
```

- Скобки — в самом конце имени слоя.
- Разделитель между парами — `;`, между ключом и значением — `:`.
- Пробелы не важны.
- Если у слоя нет токена — анимации у него нет (или разработчик решает сам).

Короткая запись: `(fade-up)` == `(anim: fade-up)` — если больше ничего не нужно.

## Ключи

| Ключ            | Значения                                                                                                                     | По умолчанию     | Смысл                                                             |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------- | ---------------- | ----------------------------------------------------------------- |
| `anim`          | `fade`, `fade-up`, `fade-down`, `fade-left`, `fade-right`, `scale`, `blur-in`, `mask-up`, `count`, `parallax`, `pin`, `none` | — (обязательный) | тип эффекта                                                       |
| `trigger`       | `in-view`, `load`, `hover`, `click`, `scroll`                                                                                | `in-view`        | когда запускать                                                   |
| `dur`           | число, мс                                                                                                                    | `600`            | длительность                                                      |
| `delay`         | число, мс                                                                                                                    | `0`              | задержка старта                                                   |
| `ease`          | `out`, `in`, `in-out`, `linear`, `spring`                                                                                    | `out`            | характер движения                                                 |
| `distance`      | число, px                                                                                                                    | `24`             | сдвиг для slide / глубина parallax                                |
| `stagger`       | число, мс                                                                                                                    | —                | **ставится на родителя**: дети появляются по очереди с этим шагом |
| `once`          | `true`, `false`                                                                                                              | `true`           | проигрывать один раз или каждый раз при входе в вид               |
| `start` / `end` | напр. `top 80%`, `top top`, `bottom top`                                                                                     | —                | точки скролла для `trigger: scroll` и `anim: pin`                 |

## Что где писать

- **Появление одного элемента** — токен на самом элементе:
  `Hero-title (anim: fade-up; delay: 100)`
- **Группа, которая въезжает по очереди** (карточки, пункты списка) — токен на
  родителе-контейнере, а не на каждом ребёнке:
  `Feature-cards (anim: fade-up; stagger: 80)`
  Если у ребёнка свой токен — он переопределяет родительский для этого ребёнка.
- **Число, которое накручивается** (`120+`, `98%`):
  `Stat-value (anim: count; dur: 1200)` — конечное значение берётся из текста слоя.
- **Фоновый слой, который едет медленнее контента при скролле**:
  `Bg-shape (anim: parallax; distance: 120; trigger: scroll)`
- **Секция, которую «прибивает» на время скролла** (сложные скролл-сцены):
  `Story-section (anim: pin; start: top top; end: bottom top)` — плюс отдельно
  словами/в прототипе опиши, что внутри происходит по мере прокрутки: таймлайн
  из одной подписи не восстановить.

## Примеры

```
Nav                 (anim: fade-down; trigger: load; dur: 400)
Hero-title          (anim: fade-up; delay: 100)
Hero-subtitle       (anim: fade-up; delay: 200)
Hero-cta            (anim: scale; delay: 320; ease: spring)
Logos-row           (anim: fade; stagger: 60)
Feature-cards       (anim: fade-up; stagger: 90; distance: 32)
Metric-value        (anim: count; dur: 1400)
Gallery-image       (anim: blur-in; dur: 800)
Decor-blob          (anim: parallax; distance: 140; trigger: scroll)
Footer-cta          (anim: fade-up; once: false)
```

## Чего токен НЕ заменяет

- **Сложные скролл-нарративы** (несколько элементов по общей шкале прокрутки,
  как в ride-over лендингах) — это таймлайн, а не свойство одного слоя. Нужен
  прототип Figma или отдельное описание последовательности.
- **Микро-взаимодействия по состоянию** (ховер кнопки, переключение табов) —
  обычно решаются на уровне компонента, токен не обязателен.
- Точный тайминг «под музыку» — токен задаёт намерение, финальную полировку
  разработчик подгоняет на живой странице.

## Reduced motion

Разработчик обязан уважать системную настройку «уменьшить движение»: при ней все
эти анимации схлопываются в мгновенное появление. Отдельно в макете помечать не
нужно — это делается автоматически.
